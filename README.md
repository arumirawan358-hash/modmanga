# modmanga

Repo untuk modding game "The Manga World".

## Struktur
- `apk/` — tempat simpan file APK asli (The Manga World)
- Mod akan dikembangkan setelah APK tersedia di repo ini

## Fitur mod yang direncanakan
- Mod Menu On/Off (toggle semua mod)
- Always Viral saat publish manga
- Unlimited Money
- Mod tambahan berguna lainnya
