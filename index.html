Tentang & FAQ

Bagaimana ini bisa gratis?

Benarkah tanpa API key?

Benar. Chat dan gambar memakai API publik Pollinations yang tidak memerlukan kunci maupun pendaftaran. Suara memakai mesin suara bawaan browser. Fitur tambahan (Puter) memakai akun gratis, bukan API key.

Kenapa chat harus menunggu 30 detik?

Kuota gratis Pollinations dibatasi per alamat IP: satu permintaan teks per 30 detik dan satu gambar per 45 detik. Aplikasi menampilkan hitungan mundurnya. Mau tanpa jeda? Hubungkan akun Puter gratis di atas, atau pasang API sendiri.

Apakah dataku dikirim ke suatu tempat?

Hanya teks yang kamu kirim ke penyedia AI saat meminta jawaban. Riwayat percakapan, galeri, dan pengaturan tetap di perangkatmu (localStorage & IndexedDB) dan tidak pernah kami unggah.

Suara browser kedengarannya berbeda di tiap perangkat?

Mesin suara bawaan bergantung pada sistem operasi dan browser. Chrome di Android/desktop biasanya punya suara Bahasa Indonesia yang natural. Untuk hasil paling realistis dan bisa diunduh MP3/WAV, pakai Puter Neural.

Boleh dipakai komersial?

Kode aplikasi ini bebas kamu pakai. Untuk hasil gambar dan suara, ikuti ketentuan masing-masing penyedia (Pollinations, Puter, dan model di baliknya).
