# CARA UPLOAD APK "THE MANGA WORLD" KE REPO INI

File APK berukuran 30 MB, jadi tidak bisa lewat website GitHub (batas 25 MB).
Pakai cara berikut lewat terminal/command prompt di komputer kamu:

## 1. Install Git (kalau belum punya)
- Windows: download dari https://git-scm.com/download/win
- Mac: `brew install git` atau download dari https://git-scm.com/download/mac
- Linux: `sudo apt install git`

## 2. Clone repo ini
```
git clone https://github.com/arumirawan358-hash/modmanga.git
cd modmanga
git checkout arena/83e10e18-modmanga
```

## 3. Copy file APK kamu ke folder `apk/`
Taruh file APK "The Manga World" di dalam folder `apk/` di dalam repo.
Contoh: `apk/The-Manga-World.apk`

## 4. Tambah, commit, dan push
```
git add apk/The-Manga-World.apk
git commit -m "upload The Manga World APK"
git push origin arena/83e10e18-modmanga
```

## 5. Selesai!
Kamu ngga perlu buat akun GitHub baru atau setting apa-apa. Cukup jalankan perintah di atas di terminal.
